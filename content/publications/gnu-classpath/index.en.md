abstract: >
  GNU Classpath is a free implementation of the Java core class
  libraries. Its permissive license has made it a catalyst for a
  diverse set of virtual machines and compilers — GCJ, Jikes RVM,
  IKVM.NET, Kaffe, and others — with sometimes conflicting design
  goals. The talk shows how Classpath serves them all, and demonstrates
  Eclipse and Tomcat running on an entirely free stack.
