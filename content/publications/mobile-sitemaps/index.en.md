abstract: >
  An extension of the Sitemaps mechanism for mobile-formatted content.
  A site’s sitemap can declare the format of each document — XHTML
  Mobile Profile, WML, i-mode HTML — so a search engine can crawl it
  with a matching client profile and index the mobile pages separately
  from their desktop equivalents, rather than fetching everything as a
  desktop browser would.
