abstract: >
  ISO 19107 (räumliches Schema) bietet eine so reiche Sammlung von
  Modellierungskonstrukten, dass sich dieselbe Geometrie auf mehrere
  Arten beschreiben lässt – was die Interoperabilität erschwert.
  ISO 19137 definiert ein kleines, breit implementierbares Kernprofil
  davon: eine gemeinsame Teilmenge, auf die sich jede Gemeinschaft
  verlassen und die sie für ihre Zwecke erweitern kann.
