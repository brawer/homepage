{{/* Renders a square-cropped thumbnail for gallery grids (Art/Publications/Projects list pages, tag pages) — AVIF and WebP sources at several widths, WebP fallback. Crops to 1:1 (smart-anchored per hugo.toml's [imaging] anchor setting), since DESIGN_BRIEF wants "thumbnails cropped to a consistent aspect ratio for visual rhythm" and a square grid reads well as a mobile photo-grid. Full/uncropped images belong on detail pages — use picture.html for those instead. Params (pass as a dict): image (required) Page Resource, e.g. .Resources.GetMatch "foo.webp" alt (required) alt text anchor (optional) Fill anchor: "smart" (default — smart-crop, which searches crops at multiple zoom levels and may zoom in on the salient region) or "center" (plain center crop, no zoom). Pass "center" for an already-square, hand-curated `teaser` so it renders verbatim rather than being re-cropped by the algorithm — see gallery-grid.html. widths (optional) slice of target widths in px, ascending; default (slice 400 800 1200). 400 is roughly 1/3 of a present-day phone's screen width — sized for a 3-column mobile grid, "similar to a photos app"; 800/1200 cover 2x/3x device pixel ratios on that same grid cell. sizes (optional) sizes attribute; default "33vw" (3-col grid) class (optional) CSS class(es) for the loading (optional) "lazy" (default) or "eager" */}} {{ $image := .image }} {{ $widths := .widths | default (slice 400 800 1200) }} {{ $sizes := .sizes | default "33vw" }} {{ $anchor := .anchor | default "smart" }} {{ $avifSet := slice }} {{ $webpSet := slice }} {{ range $w := $widths }} {{ $avif := $image.Fill (printf "%dx%d avif %s" $w $w $anchor) }} {{ $webp := $image.Fill (printf "%dx%d webp %s" $w $w $anchor) }} {{ $avifSet = $avifSet | append (printf "%s %dw" $avif.RelPermalink $w) }} {{ $webpSet = $webpSet | append (printf "%s %dw" $webp.RelPermalink $w) }} {{ end }} {{ $fallbackWidth := index $widths 0 }} {{ $fallback := $image.Fill (printf "%dx%d webp %s" $fallbackWidth $fallbackWidth $anchor) }}
